# Data_Science_Portfolio

**1.HR Analytics: Employee Attrition Analysis**
A Python-based HR analytics project evaluating employee demographics, work environment factors, and key drivers behind employee attrition using data preprocessing and exploratory analysis.

Dataset
File: Human_Resources.csv (1,470 rows, 35 columns)
Features: Demographics (Age, Gender), Job Details (Department, Role, Income), Work Conditions (OverTime, BusinessTravel), and Tenure/Satisfaction metrics.

Python Libraries:
Pandas, NumPy,Matplotlib, Seaborn

Key Preprocessing Steps:
Validated dataset structure and confirmed zero missing values.
Encoded binary categorical variables (Attrition, OverTime, Over18) into 1/0 numerical values.
Analyzed distribution and summary statistics across numerical features.

**Sales Analytics: Revenue & Performance Tracking**
A Python-based analytics project evaluating sales pipelines, regional performance, and product revenue trends to optimize sales strategy.

DatasetFile: Sales_Data.csv

Key Features: Order ID, Sales Region, Product Category, Unit Price, Quantity Sold, Discount, Total Revenue, and Customer Segment.

Tech Stack:
Python, Pandas, NumPy, Matplotlib, Seaborn

Workflow Steps
Data Cleaning: Handle missing values, remove duplicate orders, and format transaction dates.

Feature Engineering: Calculate net revenue, profit margins, and average order value (AOV).

Categorical Encoding: Map regions, sales channels, and product categories to numerical indicators.

EDA & Trend Analysis: Analyze top-performing products, seasonal sales trends, and regional revenue distribution.

Categorical Encoding: Encode channels and campaign types into numerical variables.

EDA & Segmentation: Analyze channel performance and apply RFM/K-Means clustering for customer segmentation.
